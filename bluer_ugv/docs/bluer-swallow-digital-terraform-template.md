# [Bluer Swallow](./bluer-swallow.md): Terraform

## Ubuntu

> ⭐️ preferred.

> ⚠️ camera needs work. 🔥

1. follow [RPi-ROS](https://github.com/kamangir/bluer-ai/blob/main/bluer_ai/docs/install/RPi-ROS.md).

2. 
```bash
@env dot cp swallow
```

## Raspbian

> ⚠️ opencv, torch, and other modules install with challenges, and likely at lower versions.

1. follow [RPi](https://github.com/kamangir/bluer-ai/blob/main/bluer_ai/docs/install/RPi.md) (use headless).

2. run `@seed swallow_raspbian clipboard` in another terminal and the seed 🌱 into the ssh window. (needs work 🔥)

3. run, 
```bash
@env dot cp swallow-raspbian
```
