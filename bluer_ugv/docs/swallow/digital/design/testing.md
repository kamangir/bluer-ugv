# swallow: digital: design: testing

- [test the computer(s)](./computer/testing.md).
- test the gearboxes and motors using [adapter-bus](https://github.com/kamangir/bluer-sbc/blob/main/bluer_sbc/docs/adapter-bus.md) and [pwm-generator](https://github.com/kamangir/bluer-sbc/blob/main/bluer_sbc/docs/pwm-generator.md).
- validate the connection from the charging port to the battery, through the switch, through the voltmeter/ammeter, into the computer connections.
- turn the computers on, validate the session, validate bps, shutdown.
